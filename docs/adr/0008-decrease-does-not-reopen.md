# ADR 0008: A decrease does not reopen approvals

Status: Accepted (Nov 2026)

## Context

Approving ₹21.5L and then seeing ₹21.11L should not ask for approval again.

## Decision

For amount, 90-day total and early-start amount, only an increase reopens; other material facts reopen on any change.

## Consequences

Fewer needless re-approvals; tested.
